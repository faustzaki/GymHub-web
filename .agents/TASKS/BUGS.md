## Bug Report Template

Gunakan format berikut saat menambahkan bug baru:

```markdown
### BUG-XXX: [Judul Bug]

| Field | Value |
|---|---|
| **Severity** | 🔴 Critical / 🟡 Medium / 🟢 Low |
| **Status** | Open / In Progress / Fixed / Won't Fix |
| **Found By** | [Nama / AI Agent] |
| **Found Date** | YYYY-MM-DD |
| **Fixed Date** | — |
| **Related File** | `path/to/file` |

**Description:** Apa yang terjadi?

**Steps to Reproduce:**
1. Step 1
2. Step 2
3. Step 3

**Expected:** Apa yang seharusnya terjadi?

**Actual:** Apa yang terjadi sebenarnya?

**Fix:** (isi setelah bug di-fix)
```
